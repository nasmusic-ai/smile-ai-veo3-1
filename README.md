# SMILE AI VEO3

A React application for generating videos using Google's Veo 3.1 model via the Gemini API.

## 🚀 Getting Started

### 1. Initialize Git
To connect this project to GitHub, first initialize a local repository:

```bash
git init
git add .
git commit -m "Initial commit"
```

### 2. Create a Repository on GitHub
1. Go to [GitHub.com/new](https://github.new).
2. Name your repository (e.g., `smile-ai-veo3`).
3. Click **Create repository**.

### 3. Connect and Push
Run the commands shown on GitHub in your terminal:

```bash
git remote add origin https://github.com/YOUR_USERNAME/smile-ai-veo3.git
git branch -M main
git push -u origin main
```

## 🛠 Configuration

This app requires a Google GenAI API Key. The app is configured to use a secure fallback, but for production, you should set:

- `API_KEY`: Your Google GenAI API key.

## 📱 Features

- **Veo 3.1 Video Generation**: High-quality video from image + prompt.
- **Admin CMS**: User management and approval workflows.
- **Watermarking**: Customizable branding overlays.
- **Mobile Optimized**: Responsive design for all devices.
